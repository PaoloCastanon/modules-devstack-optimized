# Línea base del sistema original

La línea base se ejecutó el 2026-10-02 en el DevStack original. `evidence/sprint2/placement` contiene GET de versión, providers, inventories, traits, resource classes y allocation candidates; también 404, creación de un provider temporal, actualización de inventario VCPU y eliminación. `evidence/sprint2/glance` contiene list/show, 404, creación, upload, PATCH, download y eliminación de una imagen pequeña. Cada petición conserva método/ruta, headers no secretos, status, headers de respuesta saneados y cuerpo cuando aplica. El binario descargado se comparó por hash y bytes sin guardarlo en Git. `evidence/sprint2/nova/scheduler-placement.log` muestra la reclamación real de recursos y `evidence/sprint2/tests/boot-states.txt` confirma `ACTIVE`. Las fixtures se usarán en `tests/compatibility/*_baseline.sh`. Para Sprint 3 faltan casos mutantes de traits/allocations, más errores de validación y cabeceras/cuerpos HTTP exactos de las llamadas de Nova.

No se registran respuestas inventadas. Los comandos se ejecutaron contra DevStack original antes de iniciar servicios Go. El token se mantiene sólo en memoria de proceso y no se imprime.
