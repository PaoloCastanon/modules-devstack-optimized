# Línea base del sistema original

No hay línea base ejecutada: `evidence/sprint2/{placement,glance,nova,tests}` contiene solamente auditoría de código upstream y host. `capture-baseline.sh` realizará GET de versión, providers, inventories, traits, resource classes, allocation candidates, imágenes y metadata; además probará 404, creará un provider propio con inventario VCPU y lo borrará, y creará/subirá/modificará/descargará/borrará una imagen pequeña propia. Cada petición guarda método/ruta, headers no secretos, status, headers de respuesta sanitizados y cuerpo cuando aplica. El binario descargado se compara por hash y bytes sin guardarlo en Git. Las fixtures se copian con `tests/compatibility/*_baseline.sh`. Aún faltan casos mutantes de traits/allocations, errores de validación y tráfico real de boot; deberán añadirse tras conocer configuración y recursos de la VM.

No se registran respuestas inventadas. Todos los comandos deben ejecutarse contra DevStack original antes de iniciar los servicios Go. El token se mantiene sólo en memoria de proceso y no se imprime.
